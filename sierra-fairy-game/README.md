# Silver Shadow's Gertech fairy-game workshop

**Start with [START_HERE.html](START_HERE.html) after downloading, or [the beginner lessons](LESSONS.md) here on GitHub.**

This is Silver Shadow's resource and source-asset handoff for her own **2.5D, Terraria-inspired fairy game in Godot**. She chooses her title, character, art treatment, mechanics and pace. Both Godot and Unity resources travel in this package. Godot is her first build; Unity is ready for later reuse.

1. [Download the complete source ZIP](https://raw.githubusercontent.com/IsekaiSensei/to-dog-open-crew/main/sierra-fairy-game/downloads/SIERRA_GODOT_UNITY_HANDOFF_v1.zip), then extract it. Reading or downloading needs no GitHub login or private Hub access. The repository’s Code → Download ZIP route also works.
2. Open **sierra-fairy-game/START_HERE.html** in a browser. Begin with lesson 01.
3. In Godot, import **Godot/SierraWorkshop/project.godot**. Press F5 to open the workspace. The scene is a clean bench for her work; the included examples are separate practice references.

| Folder | What is actually supplied |
| --- | --- |
| `Godot/SierraWorkshop` | Native Godot workspace, side-view 2D scene and orthographic 3D asset bench |
| `Godot/Examples` | Existing World Seeder foundation and Spark First Path source, separately labelled prototypes |
| `Shared/Models` | Existing crystal-metal tree, unchanged Godot source plus OBJ/MTL and GLB conversions |
| `Shared/Data` | Portable shared-world direction and a small labelled practice item/recipe schema |
| `Unity/SierraWorkshop` | Unity project scaffold, the same model/data, and a menu command to create an asset bench |
| `Unity/GertechSharedAssets.unitypackage` | Importable Unity asset container generated from the supplied Assets tree |
| `MetaQuest` | On-headset Godot instructions, desktop export path and a bounded Meta art-relay brief |
| `Guides` | Side-view mining/building roadmap, art import, troubleshooting, and SD card instructions |

**Contents are source projects and learning material.** Engine applications, Unity licensing, Jan model weights, Android SDK/export templates and a signed Quest APK are installed or downloaded separately. The card package does not install SteamOS or prove either physical device has run it.

**Assets available:** the reusable tree model, existing prototype geometry/code and portable data. A finished fairy sprite sheet/rig, terrain tileset and production audio were not found in the inspected handoff. Silver Shadow can make those in her own style. Concept illustrations do not silently become animated sprites or licensed game assets.

The [shared-world notes](SHARED_WORLD.md) preserve Gertech relationships. [STATE.md](STATE.md) records verification. [ASSET_MANIFEST.json](ASSET_MANIFEST.json) records sources and conversions. No private archive or family material is required to begin.
