The beginner path

Watch a little. Pause. Try it. Make one change yourself. YouTube needs internet; the source files and local guides remain on the card.

  1. 01 · Your first Godot projectHow to make a Video Game - Godot Beginner Tutorial

    Brackeys. Make a separate practice project. Learn the editor, nodes, scenes, movement, collision, animation, camera and UI. Change one thing yourself.

  2. 02 · The smallest amount of codeHow to program in Godot - GDScript Tutorial

    Brackeys. Practice variables, if statements, functions, arrays, dictionaries and signals. Make a counter change when an item is collected.

  3. 03 · Tile terrainTileMapLayer Basics in 4.3

    ThinkWithGames. Paint a tiny floor and cave with collision. Use TileMapLayer in current Godot; older TileMap calls need adapting.

  4. 04 · Gather resourcesCrash Course ~ How to Make a Resource Gathering Game in Godot 4!

    Chris’ Tutorials. Learn tools, hit interactions and pickups. Adapt the top-down example to side-view targeting; it is not a Terraria clone.

  5. 05 · InventoryHow to Create a INVENTORY in Godot 4 (step by step)

    DevWorm. Add item data, quantities, slots and a hotbar. First store and display one material. Keep data separate from the UI.

  6. 06 · Save and returnSaving and loading games with Godot

    Godotneers. Save the seed, player position, inventory and changed tiles. Close the game, reopen it and verify all four survive.

  7. U1 · Unity basics, when wantedHow to make a 2D Game in Unity

    Brackeys. An older Unity introduction for concepts. Follow the current official Unity Essentials course for present menus and setup.

  8. Q1 · Godot XR demonstrationsGodot XR developer channel

    Bastiaan Olij. A creator channel, not a single pinned lesson. Use the official Quest setup guide for the exact engine version.
