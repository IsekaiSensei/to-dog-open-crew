# Silver Shadow's workspace

Import project.godot in Godot 4.3+ (4.7.2 was used for this package's checks). F5 opens the start page. Open SideView2D.tscn or AssetBench3D.tscn and press F6 to run that scene. This is a workspace for Silver Shadow to build; no fairy controls or mining loop are pre-authored. Use GDScript for compatibility with the Quest editor.
