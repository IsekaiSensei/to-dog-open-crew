# Shared setup lessons

Add one small note at `<your-handle>/<date>-<topic>.md` through a fork and pull request. Use the note template in [GET_STARTED.md](../GET_STARTED.md#5-share-one-improvement-with-open-crew).

Share what you tried, what happened, one proposed improvement and the evidence. Mark untested ideas PROPOSAL. The owner reviews and merges accepted changes. Keep private project material in its own repository.

For art contributions, use the [new art format](../GET_STARTED.md#art-contributions--new-format-gradual-migration). New edits adopt it immediately; legacy originals are converted only when touched or straightforward, with remaining records marked FORMAT MIGRATION PENDING. Keep source, rights, approval and actual extraction evidence separate.
