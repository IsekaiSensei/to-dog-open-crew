# Sensei Glossary — Bowl / Page / Scroll / Book

TO WORLD / GERTECH · Public Page · Updated October 17, 2026

**Ryan said:** “public pages are everywhere.”

**Paraphrase:** Publish this glossary as a public Page. Public Pages include GitHub Pages, Facebook, TikTok and Instagram; they are not confined to chat windows.

| Term | Meaning | How it works |
| --- | --- | --- |
| **Bowl** | One agent’s own order queue. | In the supplied Grok terminology, each bed has its own bowl. Check that bowl first, then the hub. Separate ownership; cross-links and handoffs do not merge bowls. |
| **Page** | A bounded conversation or a public presentation of work. | A chat Page is working context. A public page is a deliberately published piece: a GitHub page, Facebook page or post, TikTok, Instagram, or another public surface. A Page is not restricted to temporary chat. |
| **Scroll** | A portable handoff between Pages, beds or agents. | Carry the actual instructions and required source material, identify the version, and request a receipt. A link alone is not a complete offline handoff. |
| **Book** | Durable, reusable reference material. | Memory lives in maintained Books, beyond any one chat. Books in the hub retain their access boundaries; durability does not make a private Book public. |
| **Glass** | The cleared public-facing layer. | Public Pages show material approved for that audience. Publishing an extract does not expose its whole source Book. |
| **Hub** | The shared reference and routing locations. | GitHub and Drive can host the hub. Each agent still needs actual access. A stored order is not proof that an agent received it. |

**Remember:** Bowl holds orders. Page presents work. Scroll carries work. Book preserves knowledge.

An agent’s bed is its individual working context. In the supplied Grok usage, all of Ryan’s Grok beds belong to the larger fishbowl, while each retains its own bowl. This does not combine separate apps, accounts or permissions.

## Public publishing should flow

Prepare the Page → review the words and source → QC the actual artifact → publish under Ryan’s authorization → verify its public URL → record the receipt.

A local save, a commit, a website deployment and a social post are different events. Report the event that actually happened. Public content can travel between platforms without transferring private Books or agent access.
