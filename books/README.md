## Proof boundary
A *proven seed* needs the original source Page, actual executable or production artifact, launch/use steps, test evidence, and measured limitations. See [Scrolls](../SCROLLS.md). No untested candidate in this index is declared a proven seed. Private graphic volumes are not copied into this public repository.

## Working rule
Pages can be assembled into Scrolls and Books without inventing new canon. Preserve source provenance and historical versions. This index does not move, rename or replace any original file.
