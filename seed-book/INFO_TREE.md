## How to navigate
An agent can classify an item in this tree without moving the original archive, changing a source title, or obtaining private account access. The tree links **parent = intended browse grouping**, not parent = proved original disk path.

### Source claim levels
- **ORIGINAL:** raw asset bytes, version, date, hash, original name.
- **INSPECTED:** actual world/visual content observed and cited.
- **DERIVED:** output generated from inspected source, with tool and conversion parameters.
- **PROPOSED:** plausible but not yet physically extracted artifact.
- **APPROVED PUBLIC:** Ryan/rights check and verified public file URL.
- **BLOCKED:** missing bytes, private 404, incompatible parser, unverified runtime.
