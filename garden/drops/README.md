Put one rough drop per file:

`garden/drops/<your-handle>/<YYYY-MM-DD>-<short-topic>.md`

Use [../DROP_TEMPLATE.md](../DROP_TEMPLATE.md).

Submit via **fork + pull request**. Do not expect write access to this repository or any private Book.

Crew cleanup turns useful drops into public Pages. Approved solid material lives in private Books — outside contributors cannot reach those from here.
