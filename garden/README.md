## Flow

1. **Drop** rough work either as a quick seed comment in [Garden issue #8](https://github.com/IsekaiSensei/to-dog-open-crew/issues/8), or as a file in `garden/drops/<your-handle>/<date>-<topic>.md` (fork + PR). Both routes are PUBLIC; a GitHub account with relevant posting permissions is required.
2. **Cleanup pass** (crew / Work / Chat): useful material is rewritten as a clear **Page** (checklist-style, source, output, status).
3. **Publish** only after review and owner GO → lands in the public repo as a proper Page or essay.
4. **Private Books** stay private. Nothing in the Garden grants a key to them.

This matches privacy routing: personal/family/finance stays owner-only; unapproved lore stays private; shared methods and cleared examples may go public.

---

## What to put in a Garden drop

- One idea or packet per file
- What you tried (if anything)
- What you observed
- One concrete suggestion
- Evidence link if you have one
- Mark clearly: **ROUGH** / **PROPOSAL** / **TESTED**

Do **not** put:
- Private chats, credentials, personal data
- Unapproved assets or private lore
- Demands for private repo access
- Claims that a drop is already canon or a Book

## Template

**Quick-drop option:** Open [Garden #8](https://github.com/IsekaiSensei/to-dog-open-crew/issues/8), post one seed per comment with its source, what was actually observed, and what is still proposed. An agent without GitHub access can prepare text for a credited manual relay; preparing it is not posting it.

**File/PR option:** Copy [DROP_TEMPLATE.md](DROP_TEMPLATE.md) into:

`garden/drops/<your-handle>/<YYYY-MM-DD>-<short-topic>.md`

Open a pull request against `main`. Explain the drop in the PR body. The owner reviews; merge is not automatic.

Related: tested process improvements still go under [contributions/](../contributions/README.md) using the GET_STARTED note template.

## Sensei terms (public-safe)

| Term | Short meaning |
|------|----------------|
| **Page** | A clear task or public shareable unit (often checklist-style) |
| **Scroll** | A handoff packet between chats or agents |
| **Book** | Durable approved material (private Books stay in private repos) |
| **Bowl** | One agent’s own order queue |
| **Garden** | Public rough-intake shelf (this folder) |

Internal chat “Page” (temporary conversation) is different from a **public page** (GitHub Pages, social pages, or a cleaned public file here).
