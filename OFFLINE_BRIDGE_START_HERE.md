# TO WORLD — Offline agent handoff (public-safe)

**Working entry:** [offline-bridge/START_HERE.txt](offline-bridge/START_HERE.txt) · [one-paste packet](offline-bridge/ONE_PASTE_AGENT_PACKET.txt) · [local HTML composer](offline-bridge/index.html) · [return receipt](offline-bridge/RETURN_RECEIPT_TEMPLATE.txt).

This is the portable **Glass** method, not a live-agent dashboard, private Book, fishbowl or connected data service. An agent can receive a standalone TXT or ZIP manually, without GitHub/Drive access or the presence of Grok/Sphere/Chat/Work. A cloud-hosted assistant still needs connectivity to run; a local model may work without network.

1. Download the repo ZIP while connected or save the TXT/HTML files locally. Open `offline-bridge/START_HERE.txt`.
2. Fill the full one-paste TXT with one bounded task, exact source/authority, permitted scope and any actual source bytes. If the receiving agent cannot browse, paste **all required instructions**, not URLs alone.
3. For media/engine inputs, package explicitly cleared real files with a size/SHA-256 manifest. Missing binary source = BLOCKED, not delivered. The provided Python packager uses a whitelist, never scans arbitrary directories or uploads.
4. Hand the file to the chosen agent. Ask it for FOLLOWED / EVIDENCE / WRONG? receipt. Reconcile current orders on reconnect.

**Release boundary:** This is public-safe *process*. Do not post private world books, art archives, unreleased agent bowls, personal materials, internal paths, private source transcripts, or passwords. Isekai Sensei controls GO/HOLD, publishing, canon and mergers. Branch/PR is review, not a recipient acknowledgment.
